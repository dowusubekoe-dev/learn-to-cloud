# What is DevOps

DevOps combines development and operations practices to improve software delivery.

## Release Pipeline:

| Stage | What it does |
| --- | --- |
| **Idea** | - Identify a customer or business need<br>- Define the feature, fix, or improvement<br>- Prioritize the work before development starts |
| **Code** | - Write the application or infrastructure code<br>- Review changes with teammates<br>- Store the work in version control |
| **Build** | - Compile or package the application<br>- Run automated checks and tests<br>- Create a deployable artifact |
| **Deploy** | - Release the build to an environment<br>- Automate the rollout process<br>- Verify the application is working after deployment |
| **Manage** | - Monitor performance, availability, and stability<br>- Respond to incidents or failures<br>- Maintain the running system |
| **Learn** | - Collect feedback from users and metrics<br>- Review what worked and what did not<br>- Use lessons learned to improve the next release |

**Application Development:**
- Number of changes, features, and defects fixed that are able to be pushed out into production

**IT Operations:**
- Success is primarily measured on system stability, availability

## Benefits of DevOps

1. **Velocity:** How quickly a product/application can be shipped or delivered through the release pipeline.
2. **Quality:** Consciousness on the quality or what is delivered to the public or customer. Digital reputation.
